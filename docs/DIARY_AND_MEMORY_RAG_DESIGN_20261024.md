# Daymark × Folio — 日付を起点とした日記・生活記録・ローカルRAGの設計

更新: 2026-10-24
対象: tsuhasqni-pixel/daily-ollama および tsuhasqni-pixel/rag-ollama
どちらも **AIなしで基本機能が成立する単体商品**。既存 main / release は変更しない。

## 1. 日記の朝の導線
- 「昨日の日記を書く」「今日の日記を書く」を明確に切り替える。午前中の初期選択は昨日、午後は今日。
- 手入力の日付切替・前日以外の過去日の修正も可能。日付が切り替わるときには、入力がある日のみ前日側へ保存。
- 起床・就寝時刻、5段階の主観的体調、体調メモ、日記本文を日付単位で保存。
- 習慣は本人が任意の名前で登録・停止・削除できる。チェックされた習慣だけを達成として集計。未チェックを「実施しなかった」と断定しない。
- 記録時の習慣名を日記にスナップショットで残し、習慣が後で削除されても歴史的なチェック内容が消えないようにする。

## 2. AI下書きの証拠ルール
- AIの利用は明示ボタンを押した場合のみ。Ollamaが入っていなくても日記・カレンダー・保存・検索は動く。
- 入力: **その日の日付**、本人が明示的に記入した出来事、主観的体調・メモ、**チェック済み習慣だけ**。習慣の全リストや未チェック項目はOllamaへ渡さない。
- チェック済みの習慣や体調メモがあれば日記本文なしでも短い文章案を作る。何も証拠がなければ実行しない。
- 昨日の記録は回想として、今日の記録は現時点までの記録として表現する。未来の予定・未入力の出来事を勝手に実施済みとしない。
- AIの出力は**提案**。元本文を自動上書きせず、利用者の確認後にだけ採用する。実モデルの事実誤認率は未測定。

## 3. 卓上カレンダー・CSV
- 月間カレンダーで毎日の日記の有無と短いプレビューを表示、日付をクリックで開く。
- 月別CSVは **その月の全日付を行として持つ**。日付／起床／就寝／体調／体調メモ／日記本文／チェック済み習慣／記録の有無。
- 既存の全件JSONバックアップと全件CSVは別途残す。CSV/JSONはいずれも平文ファイルであり暗号化されない。
- 日付単位の削除と「全日記削除」の二段階確認を設ける。外部に保存したCSV・JSONは別ファイルなので、アプリ内の削除が自動反映されない旨を表示する。

## 4. Folio RAGへの任意の連携
- Folioは日記・家計簿・子どもの記録・仕事/学校・その他をカテゴリーとして記録。
- 各記録に出来事の日付を任意に付与し、カテゴリー、日付範囲、日本語キーワードで検索。
- ローカル検索はOllama不要。現在は**語句一致型の小規模検索**であり、語句が一致しない曖昧な自然言語質問を確実に扱えるわけではない。
- AIボタンを押したときだけ上位の短い抜粋をローカルOllamaへ渡す。回答案には根拠のある資料ID・記録日を明示させ、UIも参照元を表示する。
- **DaymarkのJSONバックアップを利用者が選択した場合だけ**Folioに日付ごとの記録としてコピー。チェックした習慣と本文等を資料化。再取込では同じDaymark日付を更新し、重複作成を避ける。
- バックアップ取り込みは **同期ではない**。Daymark側で記録を消しても、Folio側のコピーは残る。Folioの記録は個別削除。必要に応じて両方で削除する。
- 子どもの記録や体調、家計情報は強いプライバシー保護対象。本人が許可していない外部AIサービスへの転送・GitHub/CIアーティファクトへの投入をしない。

## 5. 販売前のHOLD
- Daymarkの保存先はブラウザ localStorage、Folioの保存先はローカル SQLite。どちらも現状は**暗号化なし**。
- ブラウザデータ消去、OSユーザー共有、外部バックアップ、SQLite空きページやOSのバックアップにデータが残ることに注意。現在の削除は論理削除でありストレージの安全消去を保証しない。
- パスワードによる保護、バックアップ時の暗号化、データ削除の完全性、容量上限・性能・障害復旧・日付境界・実Ollama精度は未完了。
- 1030×768と1280×720などでの実機UI QA、正式Microsoft Store Identity / Publisher / MSIX / WACK / 審査は別工程。現行GitHub QA PASSでも販売認定ではない。

## 6. 例となる利用
**日記**: 朝に「昨日」を押す→体調と散歩/読書など実施済みチェック→出来事があれば追記→保存→任意でAI文章案を確認。

**家計簿**: Folioでカテゴリー「家計簿」・記録日を付けて収支メモを保存→「食費」で検索→該当する月・記録を表示。

**子どもの様子**: 個人が許可した範囲で「子どもの記録」カテゴリーに学校行事の記録を登録→時期と「遠足」「初めて」等の言葉で検索→必要時のみAIに出典付きで回答案を求める。

本書はローカル開発と販売向けの機能・データ分離を管理する引継ぎ仕様であり、個人の実記録を含まない。
