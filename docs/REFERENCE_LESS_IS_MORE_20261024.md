# 既存機能を磨くための参考調査 — 2026-10-24

## 参考資料
- [MarkText](https://github.com/marktext/marktext) — MITライセンス。簡潔な編集画面、Focus mode、キーボード操作、リアルタイム表示に着目。
- [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) — MPL 2.0。実際に取得した状態を明示するUI、監視機能と表示の分離、障害時の状態表示に着目。

## 開発方針
既存アプリに必要なものだけを採用し、別用途の重いライブラリは取り込まない。両リポジトリの実装コードはコピーしていないため、現時点では移植した第三者コードはない。将来ソース移植する場合は別途ライセンス精査が必要。

## Daymarkに採用
- 日記本文に集中する一時的な画面切替。起床・体調・習慣の入力内容は消えず、通常表示に戻せる。
- Escapeで集中表示終了、Ctrl/Cmd+Sで保存。
- 基本データ構造、日付切替、習慣管理、CSV/JSONバックアップ、AI任意機能はそのまま。

## Folioに採用
- ローカルOllamaの接続状態を手動確認できる。自動常時監視・ハードウェアセンサーの読込・管理者権限の要求はしない。
- ローカルOllamaへの接続確認は2秒でタイムアウトし、未接続時もキーワード検索は動作する。
- 分類・登録・検索・削除と出典表示は従来どおり。特定用途や他製品との連携は追加しない。

## 意図的に採用しない機能
- Markdownの完全WYSIWYG編集、複数テーマ、PDF出力、多機能書式パレット
- CPU/GPU温度・ファン・電圧監視、デバイスドライバー、OSの管理者権限を必要とする機能
- 常駐監視プロセスやバックグラウンドの通信ポーリング、外部サービスへの自動送信

## QA / 出荷条件
- Windows Edgeで画面幅1280、1024、720を確認し、機能を追加したことによる水平はみ出しや保存データ消失がないか確認する。
- 新機能は既存のWindows GitHub Actionsに組み込み、失敗があればブランチ内で修正する。
- Windowsランタイム・署名済みMSIX、Store Identity、プライバシー保護は別工程であり、自動テストのPASSは販売可能を意味しない。
