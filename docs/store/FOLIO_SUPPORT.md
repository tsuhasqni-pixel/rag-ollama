# Folio AI Support / サポート

- Support and bug reports / 問い合わせ・不具合報告: https://github.com/tsuhasqni-pixel/rag-ollama/issues
- Local data / 保存場所: `%USERPROFILE%\.rag-ollama\library.sqlite3`
- Backup / バックアップ: Exit Folio AI, then copy the `.rag-ollama` folder while the app is closed. / アプリ終了後に `.rag-ollama` フォルダーをコピーします。
- Delete all data / 全削除: Exit Folio AI and delete the `.rag-ollama` folder. / アプリ終了後に同フォルダーを削除します。
- Ollama: The app uses only the local endpoint `127.0.0.1:11434`. Ollama installation and model availability are managed on the user's PC.
