# Folio AI auto-upload handoff

The authoritative machine-readable handoff is generated by `store/build_msix.ps1` as `msix-out/folio-auto-upload-handoff.json` in the Store candidate Actions artifact. It contains the exact checked-out source SHA, unpack-verified manifest values, package filename, and SHA-256.

Formal route values are taken from the existing automation contracts:

- coordinator: `Windows-all-auto`
- product type: `app`
- submission kind: `update`
- build contract: `windows-data/1`
- checker contract: `windows-checker/1`
- automator contract: `windows-automator/dryrun-1`
- execution mode: `dry_run`
- checker status: `READY_CANDIDATE_NOT_CERTIFIED`

`ready_for_store_draft` remains `false`. This handoff does not authorize Partner Center upload, Save, certification submission, publication, or pricing changes.
