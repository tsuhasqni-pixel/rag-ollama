# Folio — ローカル資料整理・検索（rag-ollama）

**好きな記録や資料を、自分のPCに保存して検索する独立アプリです。** 使用目的や記録の内容は利用者が自由に決めます。特定の人や用途を前提にした設計ではありません。

## AIなしでできること
- テキスト・Markdown・CSV・JSONのファイルをテキストとして読み込み、または本文を直接入力してローカル保存
- 「メモ・記録」「資料・書類」「数値・表」「その他」の汎用分類を使い、任意の日付を付けて整理
- キーワード検索、分類・日付範囲の絞り込み、検索結果の抜粋表示
- 保存済み資料の一覧・個別削除

## 任意のAI補助
ローカルのOllamaが使える場合に限り、利用者の操作で検索結果の抜粋から回答案を生成します。参照した資料ID・日付・タイトルも表示します。AIを使わない場合も検索できます。

## 起動
```bash
python server.py
```
ブラウザから http://127.0.0.1:8775 を開きます。Python標準ライブラリのみで基本機能が動作します。

## 製品の独立性とデータ保護
- **他のアプリとの専用連携、自動同期、専用バックアップの取り込みはありません。** 通常のファイル読み込みだけをサポートします。
- ローカルSQLiteの文章は現状**暗号化されていません**。共有PCで個人情報や重要資料を保存する用途は、暗号化・データ保護対応が完了するまで商品化HOLDです。
- 既存の開発版に存在した分類名は、登録済みの記録を失わず汎用分類へ移す処理で引き継ぎます。
- PDF/Word抽出・大規模索引・意味検索・実Ollama精度検証は今後の課題です。
- Microsoft Store用MSIX、正式Identity、Windows実機/認定QAは未完了。

## 保存場所がわからない資料を探す
資料名や保存日を覚えていなくても、検索欄に**本文で覚えている単語**を入力するだけで検索します。入力後に短い間隔で検索が実行され、元の資料名、分類、記録日、該当語、本文抜粋を表示します。

複数語は全語に一致する資料を優先しつつ、一部の語だけ一致した資料も候補に残します。旧版の最新500件制限を除き、古い登録資料も含めて候補を照合します。検索はSQLiteのローカルスキャンによる簡易方式で、今後大規模なファイル数では速度/索引最適化が必要です。

AIは別ボタンで任意に利用。資料検索そのものにはOllamaも外部APIも必要ありません。他のアプリとの専用連携はありません。

テスト: Pythonの500件超・本文検索・複数語順位テストとWindows Edge入力中検索テスト。
