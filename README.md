# Folio — ローカル資料検索 / RAG候補（rag-ollama）

## 商品の独立機能
**Ollamaなしで日本語キーワード検索が可能。** ローカルSQLiteにテキスト資料を登録し、語句をすべて含む資料を検索して抜粋と一致度を表示します。
Ollamaが利用可能な場合だけ、ユーザーが押したボタンで検索上位3資料の短い抜粋から回答を生成します。

## 起動
```bash
python server.py
```
ブラウザで http://127.0.0.1:8775 を開きます。Python標準ライブラリ以外不要。ファイル登録はテキスト、CSV、JSON、Markdownが対象。

## 販売前に必要な拡張
- PDF/DOCXの抽出は現在未移植。旧Local LLM Workbench側の抽出処理をライセンス/依存も含めて確認してから追加する。
- 現在の検索は500件までを単純走査する小規模版で、全文検索大規模化・索引最適化・検索精度実測が必要。
- SQLite保存は暗号化していない。バックアップ・削除・データ暗号化UIの追加が必要。
- UIと検索はローカル専用。ユーザー資料を外部サービスへアップロードしない。
- Store版のWindows MSIX / 初回起動 / Identity / Publisher / セキュリティ/性能QAは未実施。

これは完成済み商用RAGエンジンではなく、独立実装への第一段階です。
